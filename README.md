# 《盗墓笔记》编年史项目交付说明

> 依据南派三叔《盗墓笔记》正传八部 + 外传《藏海花》《沙海》《重启》剧情整理（凭记忆考据，非官方文本）。
> 用途：个人兴趣研究。禁止商业使用与全文转载。

## 交付物清单

| 文件 | 说明 |

| `1_编年史_主时间线.md` | 全系列按时间排序的主时间线（正传八部+外传，含年代体系） |

| `raw/da1~da6_*.md` | 6 个子代理原始考据稿（可追溯） |

## 坐标说明
- 凡能对应现实地名（城市/山脉/海域）均用真实坐标（WGS84，两位小数）。
- 纯虚构地点（墓室内部、青铜门内等）锚定最近现实点，`coords_note` 中注明"虚构锚点"。

## 使用方式
1. 浏览器直接打开 `map/盗墓笔记地图.html`（需联网加载 OpenStreetMap 瓦片与 Leaflet）。
2. 左侧可勾选地点类型筛选、切换路线/标签图层；点任意标记查看时间/人物/发现详情。
3. 结构化数据可用任意文本编辑器或 GIS 打开。

## 项目方法
本项目由项目经理（DeepSeek）组织 6 个子代理分工协作产出：
- DA-1~4：正传八部分卷考据（卷一~二、三~四、五~六、七~八）
- DA-5：外传三篇（藏海花/沙海/重启）
- DA-6：全地点坐标锚定考据（现实 28 处 + 虚构锚定 17 处）
- 项目经理负责整合、质检、构建地图与文档
