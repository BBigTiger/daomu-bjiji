## 坐标说明
- 凡能对应现实地名（城市/山脉/海域）均用真实坐标（WGS84，两位小数）。
- 纯虚构地点（墓室内部、青铜门内等）锚定最近现实点，`coords_note` 中注明"虚构锚点"。

## 使用方式
1. 浏览器直接打开 `map/盗墓笔记地图.html`（需联网加载地图瓦片与 Leaflet/ECharts）。
2. 顶部 6 个模式切换：**地图**（时代层切换/筛选/图层/人物轨迹）/ **时间线**（搜索定位）/ **谜题线**（24条追踪）/ **编年史**（按卷浏览，点击定位）/ **关系图谱**（人物共同出场）/ **九门谱系**（老九门世家跨代连线）。
3. 地图模式含 **🕰️ 时代层** 开关：现代·正传 / 民国·老九门 / 古代·传说，可分别查看。
4. 结构化数据可用任意文本编辑器或 GIS 打开。

## 数据校验
```bash
node lint_data.mjs
```
校验词表/坐标范围/引用完整性/谜题线/轨迹引用/版权门禁（引号片段）。

## 项目方法
本项目由项目经理（DeepSeek）组织 7 个子代理分工协作产出：
- DA-1~4：正传八部分卷考据（卷一~二、三~四、五~六、七~八）
- DA-5：外传三篇（藏海花/沙海/重启）

- DA-7：前传《老九门》考据（九门世家/民国事件/长沙地点/谜题/谱系，含张小鱼线）
- 项目经理负责整合、质检、构建地图与文档
