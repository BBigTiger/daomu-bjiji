## 坐标说明
- 凡能对应现实地名（城市/山脉/海域）均用真实坐标（WGS84，两位小数）。
- 纯虚构地点（墓室内部、青铜门内等）锚定最近现实点，`coords_note` 中注明"虚构锚点"。

## 使用方式
1. 浏览器直接打开 `map/盗墓笔记地图.html`（需联网加载地图瓦片与 Leaflet/ECharts）。
2. 顶部 5 个模式切换：**地图**（筛选/图层/人物轨迹）/ **时间线**（搜索定位）/ **谜题线**（17条追踪，点击看关联事件）/ **编年史**（按卷浏览，点击章节地图定位）/ **关系图谱**（人物共同出场力导向图，点击节点定位）。
3. 结构化数据可用任意文本编辑器或 GIS 打开。

## 数据校验
```bash
node lint_data.mjs
```
校验词表/坐标范围/引用完整性/谜题线/轨迹引用/版权门禁（引号片段）。

## 项目方法
本项目由项目经理（DeepSeek）组织 6 个子代理分工协作产出：
- DA-1~4：正传八部分卷考据（卷一~二、三~四、五~六、七~八）
- DA-5：外传三篇（藏海花/沙海/重启）
- DA-6：全地点坐标锚定考据（现实 28 处 + 虚构锚定 17 处）
- 项目经理负责整合、质检、构建地图与文档
